# DracoLearn 🐉 — เรียนภาษาอังกฤษกับเบลซ มังกรน้อย

เกมเรียนภาษาอังกฤษสำหรับผู้เรียนภาษาไทย ที่ได้แรงบันดาลใจจากกลไกของ Duolingo
(ระบบหัวใจ, XP, Streak, บทเรียนแบบ Unit, Achievement) แต่ออกแบบแบรนด์ ชื่อ
มาสคอต และหน้าตาขึ้นใหม่ทั้งหมด — **ไม่ใช้โลโก้ ตัวการ์ตูน หรือชุดสีของ
Duolingo โดยตรง** เพื่อไม่ให้ละเมิดทรัพย์สินทางปัญญาของแบรนด์ต้นแบบ

สร้างด้วย **Python + Pygame** ล้วน ๆ ไม่มี Backend ไม่ต้องต่อเน็ต
เสียงเอฟเฟกต์ทั้งหมดสังเคราะห์ขึ้นเองในโค้ด (ไม่มีไฟล์เสียง/ภาพภายนอกที่ต้องแนบ)

---

> เอาโปรเจกต์ขึ้น GitHub: ดู `GITHUB.md`

## 1. การติดตั้ง

ต้องมี Python 3.9 ขึ้นไป จากนั้นรัน:

```bash
pip install -r requirements.txt
```

หรือระบุแพ็กเกจตรง ๆ:

```bash
pip install pygame numpy pyttsx3
```

> ⚠️ ต้องมี `pyttsx3` ด้วยเสมอ ไม่งั้นระบบเสียงพูด (TTS) จะไม่ทำงานเลย (ปุ่ม "ฟังเสียง"/
> "ฟังโจทย์" จะเงียบ) คำสั่งรุ่นเก่าที่มีแค่ `pip install pygame numpy` ตกหล่น `pyttsx3` ไป
> ถ้าเคยรันคำสั่งนั้นมาก่อน ให้รัน `pip install pyttsx3` เพิ่มอีกที
>
> บน Windows ถ้าติดตั้ง pyttsx3 แล้วยังไม่พูด ให้รัน `python test_tts.py` เพื่อดูสาเหตุ
> ที่แท้จริง (มักเป็นเพราะยังไม่ได้ติดตั้งเสียงพูดใน Windows Settings > Speech หรือ
> pywin32 ยังไม่ได้รัน post-install script)
>
> การอ่านโจทย์ภาษาไทยต้องมีเสียงพูดภาษาไทยติดตั้งในระบบด้วย: ไปที่ Windows Settings >
> Time & language > Language & region เพิ่มภาษาไทย แล้วติดตั้ง Speech ใน Language options
> (หรือเพิ่มเสียงไทยจาก Settings > Time & language > Speech > Manage voices) จากนั้นปิดและ
> เปิดเกมใหม่ ปุ่ม "ฟังโจทย์" จะแจ้งเตือนหากยังไม่พบเสียงไทย

## 2. วิธีรัน

```bash
python main.py
```

ความคืบหน้าของผู้เล่นจะถูกบันทึกอัตโนมัติลงไฟล์ `save_data.json`
(สร้างขึ้นในโฟลเดอร์เดียวกับ `main.py` ตอนรันครั้งแรก)

## 4. ฟีเจอร์ที่เพิ่มเข้ามาใหม่ล่าสุด

- **บัญชีทดลอง 0001-0010**: `save_data.json` ที่แถมมามีผู้เล่น 10 คน ชื่อ=รหัสผ่านเหมือนกัน (เช่น ชื่อ `0001` รหัส `0001`) XP/Streak/อันดับ Challenger/ความแม่นยำต่างกัน ลบไฟล์นี้ได้ถ้าไม่ต้องการ

- **หน้าสถิติการเรียน** (ปุ่ม "สถิติการเรียน" บน Dashboard) วาดกราฟด้วย pygame ล้วน ๆ ไม่ใช้ไลบรารีกราฟ:
  - กราฟแท่ง **XP 7 วันล่าสุด** (วันนี้เป็นสีส้ม, แท่งโตแบบแอนิเมชัน, แกน Y ปัดเป็นเลขกลม ๆ)
  - **ความแม่นยำแยกตาม Unit** (Unit 1-5 + แถว Challenger) แถบสีเขียว ≥80% / เหลือง ≥60% / แดง <60%
  - **หัวข้อที่ผิดบ่อย** Top 5 พร้อมบอกว่าอยู่ Unit/บทไหน ผิดกี่ครั้งจากกี่ครั้ง
  - เก็บข้อมูลลงเซฟอัตโนมัติ (`xp_history`, `unit_stats`, `question_stats`) เซฟเก่าเปิดได้ปกติ (วันนี้ถูกเติมให้ จากวันก่อนหน้าจะเริ่มนับใหม่)
  - ตรรกะคำนวณอยู่ใน `game/stats.py` (ไม่แตะ pygame ทดสอบง่าย) ส่วนหน้าจออยู่ `game/screens/stats.py`
- **Challenger แบบโหด** (ค่าทั้งหมดปรับได้ใน `config.py` ส่วน `SURVIVAL_*`):
  - **คอมโบ**: ตอบถูกติดกันทุก 3 ข้อ ได้เวลาเพิ่ม +1 วินาทีต่อข้อ (สูงสุด +5) ตอบผิดคอมโบขาด
  - **ไอเท็มช่วยชีวิต** มีอย่างละ 1 ตอนเริ่มรอบ กดปุ่มด้านล่างหรือแป้น F1/F2/F3:
    **50:50** ซ่อนตัวเลือกผิด 2 ข้อ (ใช้ได้กับข้อเลือกตอบ) · **แช่แข็ง** หยุดเวลา 8 วินาที · **ข้าม** เปลี่ยนข้อโดยไม่เสียเวลา
  - **บอส**: ตอบข้อปกติครบ 8 ข้อ บอสโผล่ = ข้อยากกว่าระดับปัจจุบัน 2 ระดับ 3 ข้อติดต่อกัน (ห้ามใช้ไอเท็ม)
    ชนะ +15 วินาทีและได้ไอเท็มสุ่มเพิ่ม 1 ชิ้น · แพ้ (ตอบผิดสักข้อ) โดนหักเวลาเพิ่มอีก 10 วินาที
  - สถิติสะสมในโปรไฟล์: `challenger_runs`, `challenger_best_combo`, `challenger_bosses_beaten` (แสดงตอนจบรอบ)
  - ทดสอบ: `python test_challenger_hardcore.py` และ `python test_stats.py`

- **สลับตำแหน่งตัวเลือกทุกข้อ (โหมดปกติ + Challenger)**: ข้อเลือกตอบ (`mcq`) และฟังแล้วเลือก (`listen_mcq`) จะสุ่มสลับตำแหน่งช่องตัวเลือกใหม่
  ทุกครั้งที่ขึ้นข้อใหม่ เดิมเฉลยถูกเขียนไว้ตัวเลือกแรกในคลังโจทย์ 145 จาก 147 ข้อ (โจทย์ Challenger ทั้ง 45 ข้อ) ทำให้เฉลยอยู่ช่องซ้ายบนเกือบตลอด
  ตอนนี้เฉลยตกช่องไหนก็ได้เท่า ๆ กัน (~25% ต่อช่อง)
  - ตำแหน่งคงที่ตลอดข้อนั้น (วาดซ้ำ/ตอนเฉลยตัวเลือกไม่ขยับ) ส่วนข้อถัดไปสุ่มใหม่ ข้อเดิมที่กลับมาถามอีกก็สุ่มใหม่
  - สลับเฉพาะ "ลำดับที่โชว์" ไม่แก้ลำดับ `options` ในคลังโจทย์ และตรวจคำตอบจากข้อความตัวเลือก ไม่ผูกกับตำแหน่ง
    โจทย์ที่เพิ่มเองจึงไม่ต้องสลับลำดับเองอีก จะวางเฉลยไว้ตำแหน่งไหนก็ได้
  - ข้อเรียงคำ (`word_order`) สลับแผ่นคำอยู่แล้วเหมือนเดิม ข้อพิมพ์เองไม่มีตัวเลือกจึงไม่เกี่ยว
  - `test_option_shuffle.py` เช็กว่าทุกข้อได้ตัวเลือกครบชุดเดิม เฉลยโผล่ได้ทุกช่อง ลำดับนิ่งตอนวาดซ้ำ/เฉลย และกดช่องไหนได้ตัวเลือกที่แสดงในช่องนั้นจริง

- **ระบบแต่งตัวมาสคอต "ตู้เสื้อผ้าของเบลซ"**: เข้าได้จากปุ่ม `แต่งตัวมาสคอต` บนหน้าหลัก (หรือกดที่ตัวมาสคอตเลย)
  - ของแต่งตัว **22 ชิ้น** ใน 4 ช่อง ใส่ซ้อนกันได้ทุกช่อง: หมวก 8 / แว่นตา 4 / เครื่องประดับ 4 / สีตัว 6
    (ช่องหมวก/แว่น/เครื่องประดับเลือก "ไม่สวม" ได้ ส่วนสีตัวต้องมี 1 สีเสมอ ค่าเริ่มต้นคือส้มไฟ)
  - กดการ์ดที่ปลดล็อกแล้วเพื่อสวมทันที (บันทึกอัตโนมัติ) ของที่ยังล็อกจะโชว์มืด ๆ พร้อมเงื่อนไข กดแล้วมีข้อความบอก
    มีปุ่ม `สุ่มชุด` (สุ่มจากของที่ปลดแล้ว) กับ `ถอดทั้งหมด` (สีตัวคงเดิม)
  - **มาสคอตทุกหน้าใส่ชุดเดียวกัน**: หน้าหลัก, ระหว่างทำโจทย์, หน้าสรุปบท, หน้าตายของ Challenger, หน้าล็อกอิน (หน้าล็อกอินใช้ชุดเริ่มต้นเสมอ)
    แต่ละโปรไฟล์จำชุดของตัวเอง สลับผู้เล่นแล้วชุดเปลี่ยนตาม
  - **ปลดล็อกจากการเล่นจริง** (ไม่มีร้านค้า/เหรียญ): ของง่าย ๆ ได้จากเลเวล/เรียนจบบท/ความสำเร็จ ส่วนของโหด ๆ ผูกกับระดับ Challenger ที่เคยไปถึง
    เมื่อกลับหน้าหลักหลังปลดล็อกของใหม่ จะมีข้อความแจ้ง (ครั้งเดียวต่อชิ้น)

    | ช่อง | ของ (เงื่อนไข) |
    |---|---|
    | หมวก | หมวกปาร์ตี้ (ฟรี), หมวกแก๊ป (เรียนจบ 1 บท), หมวกเชฟ (เลเวล 3), หมวกพ่อมด (ความสำเร็จ "ขยันขันแข็ง"), หมวกโจรสลัด (Challenger ระดับ 4), เขาปีศาจ (ระดับ 7 Wicked Demon), มงกุฎราชา (เลเวล 8), มงกุฎเพลิง (ระดับ 10 God of Destruction) |
    | แว่นตา | แว่นกลม (เลเวล 2), แว่นกันแดด (ความสำเร็จ "ไฟลุกต่อเนื่อง"), โกเกิลนักรบ (Challenger ระดับ 5), แว่นดาว (เลเวล 6) |
    | เครื่องประดับ | โบว์ไท (ฟรี), ผ้าพันคอ (เรียนจบ 3 บท), เหรียญเกียรติยศ (ความสำเร็จ "ไร้ที่ติ"), ผ้าคลุมฮีโร่ (Challenger ระดับ 6 Ruthless) |
    | สีตัว | ส้มไฟ (ฟรี), ฟ้าน้ำแข็ง (เลเวล 4), เขียวมิ้นต์ (เลเวล 6), ชมพูบลอสซัม (เรียนจบ 8 บท), ม่วงราตรี (ระดับ 8 Hell King), ทองคำ (ระดับ 10 God of Destruction) |

  - เงื่อนไขใช้เฉพาะค่าที่ไม่ลดลงเอง (เลเวล, จำนวนบทที่จบ, ความสำเร็จ, ระดับ Challenger สูงสุดที่เคยไปถึง) ของที่ปลดแล้วจึงไม่ถูกล็อกกลับ

    เสียงไทยก็ฟังได้) ส่วนโจทย์ไทยยังอ่านด้วยเสียงไทยเหมือนเดิม — ปุ่ม "ฟังโจทย์" ใช้ได้ทั้งสองแบบ
  - ช่องว่างในโจทย์ (`____`) จะถูกอ่านออกเสียงว่า **"blank"** (บนหน้าจอยังแสดงเป็นขีดเหมือนเดิม)
  - โจทย์ยาวจะตัดขึ้นบรรทัดใหม่อัตโนมัติ ไม่ชนกับรูปมาสคอต
  - ช่องพิมพ์คำตอบเปลี่ยนป้ายเป็น "พิมพ์คำตอบเป็นภาษาอังกฤษ:" เมื่อเป็นโจทย์อังกฤษ
  - แต่ละบทตอนนี้มี 14 ข้อ (โจทย์ไทย + โจทย์อังกฤษ + โจทย์ฟัง) ผู้เล่นเดิมไม่เสียความก้าวหน้า
    เพราะรหัสบทเรียนและไฟล์เซฟไม่เปลี่ยน
- **ระบบรหัสผ่าน**: หน้าแรกมีทั้งช่อง "ชื่อผู้เล่น" และ "รหัสผ่าน" แล้ว
  - ใส่ **ชื่อใหม่** (ไม่เคยมีใครเล่นชื่อนี้มาก่อน) → ต้องตั้งรหัสผ่านอย่างน้อย 4 ตัวอักษร
    ก่อนถึงจะสร้างโปรไฟล์ใหม่ได้ ระบบจะบันทึกรหัสผ่านนี้ไว้ทันที
  - ใส่ **ชื่อเดิม** ที่เคยตั้งรหัสผ่านไว้แล้ว → ต้องพิมพ์รหัสผ่านให้ตรงกับที่เคยตั้งไว้เท่านั้น
    ถึงจะเข้าเล่นต่อได้ ถ้ารหัสผ่านผิดจะขึ้นข้อความแจ้งเตือนและไม่ให้เข้าเกม
  - โปรไฟล์เก่าที่มาจากไฟล์เซฟรุ่นก่อน (ยังไม่เคยมีรหัสผ่าน) ยังเข้าเล่นต่อได้โดยไม่ต้องใส่
    รหัสผ่าน แต่ถ้าใส่รหัสผ่านมาด้วยตอนล็อกอิน ระบบจะถือว่าเป็นการ "ตั้งรหัสผ่านครั้งแรก"
    ให้โปรไฟล์นั้นทันที (อัปเกรดให้มีรหัสผ่านจากนี้ไป)
  - รหัสผ่าน**ไม่ถูกเก็บเป็นข้อความล้วน**ในไฟล์เซฟ: แต่ละโปรไฟล์เก็บ salt สุ่ม
    (`password_salt`) และค่า SHA-256 ของ salt+รหัสผ่าน (`password_hash`) เท่านั้น
  - ช่องรหัสผ่านจะแสดงตัวอักษรที่พิมพ์เป็น `•` เสมอ (ไม่โชว์ตัวอักษรจริง)
  - หน้า **ตั้งค่า** มีปุ่ม "เปลี่ยนรหัสผ่าน" ให้กรอกรหัสผ่านเดิม (ถ้าเคยตั้งไว้) + รหัสผ่านใหม่
    + ยืนยันรหัสผ่านใหม่อีกครั้ง เพื่อเปลี่ยนรหัสผ่านของโปรไฟล์ที่ล็อกอินอยู่
  - การ "รีเซ็ตความก้าวหน้า" ในหน้าโปรไฟล์จะล้างรหัสผ่านของโปรไฟล์นั้นไปด้วย (กลับไปเป็น
    ยังไม่ได้ตั้งรหัสผ่าน เหมือนโปรไฟล์ใหม่)
- **ระบบผู้เล่นหลายคน**: ใส่ชื่อใหม่ = สร้างโปรไฟล์ใหม่ทันที ใส่ชื่อเดิม (ไม่สนตัวพิมพ์เล็ก-ใหญ่)
  = โหลดความก้าวหน้าเดิมมาเล่นต่อ (ถ้ามีรหัสผ่านต้องใส่ให้ถูกก่อน) ทุกคนแยกเก็บ
  XP/Streak/Achievement ของตัวเอง
- **ลีดเดอร์บอร์ดของจริง**: ดึงจากผู้เล่นทุกคนที่เคยเล่นเกมนี้บนเครื่องเดียวกันจริง ๆ
  (ไม่ใช่ข้อมูลจำลองอีกต่อไป) พร้อมเหรียญ 🥇🥈🥉 3 อันดับแรก และ Streak ของแต่ละคนต่อท้ายชื่อ
- **ปุ่มสไตล์ใหม่**: hover แล้วขยายตัวนุ่ม ๆ แบบสปริง (scale animation) พร้อมเงาลอยใต้ปุ่ม
- **พื้นหลังพาสเทลเปลี่ยนตามบทเรียน**: หน้าทำแบบฝึกหัดและหน้าสรุปผลใช้พื้นหลังไล่เฉดสีพาสเทล
  ทุกบทเรียนมีสีเฉพาะตัวไม่ซ้ำกันเลยทั้งเกม (แบ่งวงล้อสีเท่า ๆ กันตามจำนวนบท แต่ละ Unit เป็นโทนสีใกล้เคียงกัน 3 เฉด)
  และในบทเดียวกันแต่ละข้อย่อยจะสลับไปมาระหว่าง 2 โทน (อ่อน/เข้มขึ้นเล็กน้อย) พร้อมไล่สีนุ่ม ๆ ตอนเปลี่ยนข้อ
  ส่วนหน้าอื่น ๆ (หน้าแรก, Dashboard, เส้นทางการเรียน, โปรไฟล์, ตั้งค่า) ยังเป็นพื้นหลังเขียว-ขาวเหมือนเดิม
  (ปรับสีที่ `PASTEL_TONES` / `HUE_OFFSET` ใน `game/content.py`)
- **ระบบออกเสียงคำศัพท์ (Text-to-Speech)**: หลังตอบคำถามในแต่ละข้อ เกมจะพูดออกเสียง
  คำตอบที่ถูกต้องให้ฟังอัตโนมัติ และมีปุ่ม "🔊 ฟังเสียง" ให้กดฟังซ้ำได้
  โจทย์ภาษาไทยจะถูกอ่านให้อัตโนมัติเมื่อเริ่มข้อใหม่ และกด "ฟังโจทย์" เพื่อฟังซ้ำได้
  โดยต้องติดตั้งเสียงพูดภาษาไทยในระบบปฏิบัติการก่อน
  ในหน้าสรุปผลก็มีปุ่ม "🔊 คำศัพท์" ให้กดฟังทีละคำที่เพิ่งเรียนได้ด้วย
  ใช้เสียงพูดของระบบปฏิบัติการเอง (Windows: SAPI5, macOS: NSSpeechSynthesizer,
  Linux: espeak) ทำงานออฟไลน์ล้วน ๆ ไม่ต้องต่อเน็ต — ถ้าเครื่องไม่มีเสียงพูดติดตั้งไว้
  เกมจะแจ้งเตือนเฉย ๆ และเล่นต่อได้ปกติ (ไม่ทำให้เกม crash)
  > **Linux**: ถ้าเสียงไม่ออก อาจต้องติดตั้ง espeak เพิ่มด้วย `sudo apt-get install espeak`
- **ปรับความเร็วเสียงพูดได้**: หน้าตั้งค่ามีปุ่มเลือกความเร็ว x0.5 / x0.75 / x1 / x1.25 / x1.5
  กดเลือกแล้วมีผลทันทีกับเสียงพูดทุกจุดในเกม (คำตอบ, โจทย์, คำศัพท์ในหน้าสรุปผล) ทั้ง SAPI5
  และ pyttsx3 บันทึกค่าไว้ต่อโปรไฟล์ผู้เล่น (คนละคนตั้งความเร็วต่างกันได้)

## 5. ฟีเจอร์หลัก

- **ระบบรหัสผ่าน**: ล็อกอินด้วยชื่อ+รหัสผ่าน, เก็บรหัสผ่านแบบ hash (SHA-256 + salt) ไม่ใช่
  ข้อความล้วน, เปลี่ยนรหัสผ่านได้จากหน้าตั้งค่า (ดูรายละเอียดในข้อ 4)
- **ระบบ Gamification**: หัวใจ 3 ดวง, XP (+10 ต่อข้อถูก, +20 ต่อบทที่จบ),
  Level คำนวณจาก `xp // 100 + 1`, Streak รายวัน
- **โหมดทบทวนฝึกฝนเพื่อฟื้นฟูหัวใจ (Practice / Heart Regeneration Mode)**: หัวใจหมด
  ไม่ได้ล็อกไม่ให้เล่นต่อทันที แต่มีปุ่ม "🔥 ฝึกฝนเพื่อฟื้นฟูหัวใจ" ให้กดแทน — จะสุ่มคำถามจาก
  คลังข้อที่ผู้เล่นเคยตอบผิดมาให้ทบทวน (ถ้าไม่เคยตอบผิดข้อไหนเลยจะสุ่มจากคลังคำถามทั้งหมดแทน)
  ตอบผิดในโหมดนี้ไม่หักหัวใจซ้ำ (หัวใจหมดอยู่แล้ว) ตอบถูกครบ 5 ข้อจะได้หัวใจคืนทันที 1 ดวง
  แล้วกลับไปเล่นบทเรียนเดิมต่อจากข้อที่ค้างไว้พอดี ข้อที่เคยตอบผิดจะถูกเอาออกจากคลังทบทวน
  ทันทีที่ตอบถูก (ทั้งในบทเรียนปกติและในโหมดฝึกฝน) ถ้าตอบผิดอีกจะถูกเพิ่มกลับเข้าคลังใหม่
- **โหมด Challenger (จับเวลา/Survival)**: กดปุ่ม "โหมด Challenger" ที่หน้า Dashboard — เริ่มด้วยเวลา 60 วินาที
  ตอบถูก **+5 วินาที** ตอบผิด **-5 วินาที** เวลาหมด = **ตาย** (จบรอบ) คำถามยากขึ้นเรื่อย ๆ:
  ตอบถูกครบทุก 3 ข้อจะขึ้นระดับความยากถัดไป (ระดับ 1-10 ดูตารางในข้อ 4) ระดับ 1-3 ใช้โจทย์บทเรียนปกติ
  ซึ่งระบบแบ่งระดับให้อัตโนมัติจาก Unit ที่โจทย์อยู่ + ชนิดข้อ (เลือกตอบ < เรียงคำ < พิมพ์เอง) + ภาษาโจทย์ + ความยาวคำตอบ
  ส่วนระดับ 4-10 ใช้โจทย์ใน `bank_challenger.py` ที่กำหนดระดับเองทุกข้อ
  (อยากกำหนดเองใส่ `difficulty=1..10` ในข้อนั้นได้) ระหว่างดูเฉลยเวลาจะหยุดนับ ไม่หักหัวใจ ไม่ให้ XP
  (กันปั๊มคะแนนในตารางคะแนน) แต่เก็บสถิติ "ตอบถูกสูงสุด" ไว้ในโปรไฟล์ และข้อที่ตอบผิดจะเข้าคลังทบทวน
  ของโหมดฝึกฝนฟื้นฟูหัวใจ ปรับค่าต่าง ๆ ได้ใน `game/config.py` (`SURVIVAL_*`)
- **ตารางคะแนน Challenger (แยกจากตาราง XP)**: จัดอันดับผู้เล่นทุกคนบนเครื่องนี้ด้วยจำนวนข้อที่ตอบถูก
  มากที่สุดในหนึ่งรอบ (ถ้าเท่ากันดูระดับความยากที่ไปถึง แล้วเรียงตามชื่อ) โชว์ 10 อันดับแรก ไฮไลต์แถวของตัวเอง
  และบอกอันดับของตัวเองถ้าอยู่นอก 10 อันดับ เปิดได้จากปุ่ม "อันดับ" ที่ Dashboard หรือปุ่ม "ตารางคะแนน"
  ในหน้าสรุปตอนตาย (หน้าสรุปบอก "อันดับที่ N จาก M คน" ด้วย) คนที่ยังไม่เคยเล่นโหมดนี้จะไม่อยู่ในตาราง
- **บทเรียน 5 Unit x 3 บท (รวม 15 บท)**: Greetings, Introductions, Family,
  Food & Drinks, Daily Activities — ปลดล็อกบทถัดไปเมื่อเรียนจบบทก่อนหน้า
- **คำถาม 5 รูปแบบ x 280 ข้อ** (บทเรียนปกติ 203 ข้อ: โจทย์ไทย 45+20 ข้อ + โจทย์อังกฤษ 43+35 ข้อ + โจทย์ฟัง 60 ข้อ, โจทย์เฉพาะ Challenger 77 ข้อ; ทุกบทเรียนมี 14 ข้อ): เลือกคำตอบ (mcq),
  เรียงคำเป็นประโยค (word_order พร้อมคำหลอกให้เลือก), พิมพ์คำตอบ (translate_type)
- **Achievement 10 รายการ** (กดที่การ์ดในหน้าโปรไฟล์เพื่อดูวิธีปลดล็อกของแต่ละอัน):
  - ก้าวแรกของมังกร (เรียนจบบทแรก), ไฟลุกต่อเนื่อง (Streak 3 วัน), นักผจญภัยระดับกลาง (Level 5),
    ไร้ที่ติ (จบบทแบบไม่เสียหัวใจ), ขยันขันแข็ง (เรียนจบ 5 บท) — 5 รายการเดิม
  - **จอมปราชญ์ผู้สำเร็จการศึกษา** (เรียนจบครบทุกบทเรียนในเกมทั้งหมด), **ไฟลุกทั้งสัปดาห์**
    (Streak ต่อเนื่องครบ 7 วัน), **นักสะสม XP ตัวยง** (สะสม XP ครบ 1,000), **ตำนานผู้พิชิต
    Challenger** (ไปถึงระดับความยาก 10/Legend ในโหมด Challenger), **นักสะสมแฟชั่นตัวยง**
    (ปลดล็อกของแต่งตัวในตู้เสื้อผ้าให้ครบทุกชิ้น) — 5 รายการใหม่ ผูกกับฟีเจอร์ Challenger/Wardrobe
    ที่เพิ่มมาทีหลัง ตรวจตอนเรียนจบบทปกติและตอนจบรอบ Challenger (ไม่ต้องรอไปเรียนบทเรียนก่อน)
  - การ์ด Achievement ในหน้าโปรไฟล์คำนวณจำนวนคอลัมน์/แถวจากพื้นที่จริงเสมอ และจะย่อขนาดกล่องลง
    อัตโนมัติถ้าของเยอะเกินจะพอดีความสูงที่เหลือ จึงไม่มีทางล้นขอบการ์ด/ขอบจอ ไม่ว่าจะเพิ่ม
    Achievement ในอนาคตอีกกี่รายการก็ตาม
- **มาสคอตเบลซ**: วาดด้วย pygame.draw ล้วน ๆ มี 5 อารมณ์ที่ต่างกันทั้ง ตา + คิ้ว + ปาก + สัญลักษณ์ประกอบ (อ่านออกแม้ตัวเล็ก)
  - `happy` ยิ้มกว้าง แก้มแดง | `excited` ตาโตมีประกาย คิ้วยก อ้าปากเห็นลิ้น ประกายดาวลอยรอบหัว เด้งถี่ ๆ
  - `sad` เปลือกตาตก คิ้วหัวยก ปากคว่ำสั่น น้ำตาไหล | `worried` ตาโตรูม่านตาเล็กกวาดมองไปมา ปากหยัก เหงื่อหยด ตัวสั่น
  - `sleepy` หลับตา ปากกลมเล็กหายใจเข้าออก มีตัว Z ลอยขึ้น
  - คิ้ววาดทับแว่น คนใส่แว่นดำ/โกเกิลก็ยังเห็นอารมณ์ ขนาดทุกอย่างสเกลตามหัว จึงชัดทั้งตัวใหญ่ (หน้าแรก) และตัวเล็ก (ตู้เสื้อผ้า)
  - อารมณ์ตามสถานการณ์: ตอบถูก/ผิดแล้วสีหน้าค้างไว้ตลอดช่วงดูเฉลย (กลับเป็นปกติเมื่อขึ้นข้อใหม่),
    เหลือหัวใจดวงสุดท้ายหรือเวลา Challenger เหลือ ≤ 10 วินาที → ทำหน้ากังวล, หน้า "หัวใจหมดแล้ว" มาสคอตเศร้า
- **บันทึกอัตโนมัติ**: ทุกการกระทำ (ตอบคำถาม, เรียนจบ, ตั้งค่า) เซฟลง JSON ทันที
- **ป้องกัน Edge Case**: ไฟล์เซฟหาย/เสียหาย → เริ่มใหม่แบบปลอดภัยแทนที่จะ crash,
  ปุ่มตรวจคำตอบกดไม่ได้ถ้ายังไม่เลือก/กรอกคำตอบ

## 7. วิธีเพิ่มโจทย์ใหม่

**โจทย์ฟังแล้วตอบ**: เพิ่มด้วยตัวช่วย `_lm` (เลือกคำที่ได้ยิน) / `_lmt` (เลือกความหมายไทย) / `_lt` (พิมพ์ตามที่ได้ยิน) ใน `game/bank_listening.py` แล้วต่อรหัสใน `LISTENING_LESSON_QUESTION_IDS`
(อ่านหลักการเขียนโจทย์ฟังไว้ที่หัวไฟล์ โดยเฉพาะเรื่องคำพ้องเสียง)

**โจทย์บทเรียนปกติ**: เพิ่ม `Question(...)` ต่อท้ายลิสต์ `EXTRA_QUESTIONS` ใน `game/bank_lessons_extra.py`
แล้วใส่รหัสข้อลงใน `EXTRA_LESSON_QUESTION_IDS` ของบทที่ต้องการ (หรือแก้ `QUESTIONS` / `UNITS` ใน `game/content.py` โดยตรงก็ได้)

**โจทย์ Challenger**: เพิ่ม `_q(...)` ต่อท้ายลิสต์ `CHALLENGER_QUESTIONS` ใน `game/bank_challenger.py`
ใส่ระดับ 4-10 ในพารามิเตอร์ที่ 5 ของ `_q` (ไม่ต้องใส่ลงบทเรียนใด ๆ) ระดับที่โจทย์น้อยที่สุดควรมีอย่างน้อย 10 ข้อ
(`test_survival.py` เช็กให้)

ขั้นตอนทั่วไป:

1. เพิ่ม `Question(...)` ในไฟล์ข้างบนด้วยรหัสที่ไม่ซ้ำ
2. ถ้าเป็นโจทย์บทเรียน ใส่รหัสข้อลงใน `question_ids` ของบทที่ต้องการ
3. ถ้าเป็น**โจทย์ภาษาอังกฤษ** ให้ใส่ `prompt_lang="en"` (ค่าเริ่มต้นคือ `"th"`)
   และเขียนคำตอบ/ตัวเลือกเป็นภาษาอังกฤษ
4. ถ้าข้อนั้นมีคำตอบที่ถูกได้หลายแบบ ให้ใส่ `alt_answers=["...", "..."]` (ไม่ต้องใส่แบบตัวย่อ
   เช่น `I'm` เพราะระบบถือว่าเท่ากับ `I am` ให้อยู่แล้ว)
5. รัน `python -m unittest test_content -v` เพื่อเช็กว่าเนื้อหาไม่พัง

```python
Question("e79", "translate_type", "Type the missing word: I drink ______ every day.",
         "water", alt_answers=["some water"], explanation='"Water" means น้ำ',
         vocab="Water", prompt_lang="en")
```
